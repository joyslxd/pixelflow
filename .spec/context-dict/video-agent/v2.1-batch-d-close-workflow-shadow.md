## 结论摘要

批次 D：`video_agent_v2` Snapshot 强制 `workflows=[]`（库内 Workflow 记录仍可存在供 compaction）。FE 有 VideoAgent 投影时清空/忽略 Workflow；`workflow.progressed` 事件不写入 V2 状态；`activeSupervisorVideoTarget` 对 V2 恒为 null；`submitSupervisorAction` 在 V2 直接返回；任务板只来自 Agent Plan。`frontend_v2` 本地 `workflowProgress` / Job / action 源码合同保留。

## 核心逻辑

1. Snapshot：`orchestration_mode == video_agent_v2` → 不投影 workflows
2. FE Snapshot hydrate：有 `videoAgent` → `workflows: []`
3. Reducer：有 `videoAgentWorkspace.current` 或 `videoAgentPlan` → 忽略 `workflow.progressed`
4. UI：V2 不绑定 Supervisor workflow interrupt UI，不写 workflow explicitAction
