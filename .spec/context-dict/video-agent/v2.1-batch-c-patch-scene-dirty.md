## 结论摘要

批次 C：手动分镜编辑与「修改第 N 镜」统一落到 `patch_scene`（写 `dirty_scene_ids` + 同步 `scene_packages`）。`generate_scenes` 未传 `scene_ids` 时用 Workspace 脏镜；`variant_count=1` 成功后自动标 `edit_status=重新生成完成` 并清脏，未改镜头保持原样。`video_agent_v2` 下工作台编辑/确认生成/QC 重生成提交 Turn，不再直接 `startSceneVideosJob` / `modify_workflow`。

## 核心逻辑

1. `patch_scene` → scenes/scene_packages 镜像 + dirty + qc dirty
2. `generate_scenes` → 仅生成指定/脏镜；单版本成功自动完成；多版本仍「等待版本审核」
3. FE V2 Turn 文案：`修改分镜 {id}…` / `重新生成已修改的分镜视频` / `确认并生成分镜视频`
4. 「修改第 N 镜」NL 由服务端 Planner/思考流选 `patch_scene`；前端关键词 `isSingleSceneRevisionRequest` 已删除，不再做 FE 资产包误路由防护

## 注意事项

- `frontend_v2` 仍走 Job + `videoScenePackageEditedSceneIds`
- 多 variant 仍需 `review_generated_scenes` 选版后才清脏
- SceneEvidencePanel 用 Workspace `edit_status === "重新生成完成"` 展示完成态
