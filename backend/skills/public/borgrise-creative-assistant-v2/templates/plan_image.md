# 被嫌弃的实习生 — 暗光拍摄翻盘｜图片版 Plan

## 一、选题方向

职场逆袭剧情海报 + 暗光拍摄效果对比。

核心表达：实习生被领导嫌弃后，用苹果PRO在暗光环境拍出清晰大片，实现翻盘。

产品定位：苹果PRO = 暗光也能出大片的影像利器。

记忆句：**苹果PRO，不用灯光也能拍大片。**

## 二、选题优势

- **爆点机制**：用“领导摔照片 + 实习生被羞辱 + 暗光样张反差”做单图冲击，一眼制造剧情悬念。
- **人群**：25-35岁职场新人、摄影爱好者、手机影像升级人群。
- **转化逻辑链**：被嫌弃 → 暗光任务很难 → 苹果PRO出现 → 样张清晰对比 → 引导直播间看实拍。
- **产品剧情检验**：去掉苹果PRO，主角无法完成暗光拍摄，翻盘不成立。
- **适合图片化原因**：视频里的关键情绪点可以压缩成一张强冲突海报：左边“失败羞辱”，右边“暗光大片”。

## 三、图片规格

- 任务类型：信息流广告图片 
- 尺寸：9:16竖图
- 投放平台：抖音信息流、小红书信息流、朋友圈广告
- 转化目标：引流直播间 / 产品种草
- 风格：电影感短剧写实风 + 高端科技产品质感
- 调性：前半冷色压迫，后半暖色逆袭，形成强对比

## 四、画面元素

- **林晓**：24岁实习摄影师，浅灰衬衫，黑色西裤，神情从委屈到坚定。
- **赵总监**：45岁创意总监，深蓝西装，金框眼镜，强势压迫感。
- **苹果PRO**：钛金属深色机身，三摄模组清晰露出，作为视觉中心。
- **失败照片**：散落在地，画面模糊灰暗。
- **暗光样张**：珠宝在暗光下清晰明亮，作为“证据”。
- **直播间入口**：底部 CTA，突出“看实拍 / 限时优惠 / 直播开箱”。

## 五、主图方案

### 方案A：剧情冲突版

**画面**：

办公室走廊，照片被摔在地上。赵总监站在画面左上方，指着地上的照片怒斥。林晓蹲在地上捡照片，眼眶微红。画面右侧用高光突出她手里的苹果PRO，屏幕中显示清晰的暗光珠宝样张。

**主标题**：

被骂拍得烂，她用苹果PRO暗光翻盘

**副标题**：

暗场珠宝，也能拍出清晰大片

**CTA**：

直播间看苹果PRO暗光实拍


## 六、视觉重点

- 画面必须保留“职场冲突”和“暗光清晰对比”两个核心信息。
- 苹果PRO不能太小，要成为翻盘关键视觉。
- 暗光样张要足够亮、清晰、有质感，最好用珠宝、夜景、人像这类高反差场景。
- 文案控制在3秒内能读完，主标题不超过18字。
- 底部 CTA 简洁直接：**进直播间看实拍**。
