# UGC 真人种草视频九层公式（Seedance 2.0 专用）

> 来源：Arcads.ai UGC 视频 prompt 公式（海外投流实测）· 板爷 2026-07-10 提炼中文化
> 用途：生成「真人手机自拍种草/测评视频」的 Seedance 2.0 prompt。
> 核心目标：**让画面像真人用手机随手拍的，不是摆拍广告**——去 AI 感 = 可控的不完美。
> 九层缺一不可，跳过任何一层输出就崩。

---

## 九层结构总览

```
 1. 格式头 FORMAT HEADER    — 时长、风格、设备、光源、机位角度
 2. 人物 PERSON             — 外貌、皮肤真实纹理、穿着
 3. 场景 SETTING            — 住过人的环境、具体杂物细节
 4. 产品引入 PRODUCT INTRO   — 如何把产品拿进画面
 5. 脚本节拍 SCRIPT BEATS    — 跳切分镜 + 对白 + 动作（心脏）
 6. 语气方向 TONE           — 性格、节奏、能量（必带语速提示）
 7. 剪辑风格 EDIT STYLE      — 跳切、多角度、take拼接
 8. 技术瑕疵 TECHNICAL FLAWS — 手机画质、自然收音、光线不完美
 9. 氛围陈述 VIBE           — 一句情感锚（北极星）
```

---

## 逐层填写规范

### 第1层 格式头
**句式**：`{时长} UGC风格 {内容类型} 视频，手机拍摄，{光源}，{机位角度}。`
- **时长**：15s（Seedance上限）或10s（更紧凑）。
- **时长-对白匹配铁律**：把每句对白**用自然语速念出来计时**，塞不下就删词。每条至少1个静默动作拍。
  - 10s：2-3跳切，1-2句对白+1静默拍，钩子+punchline。
  - 15s：2-4跳切，3-4句短对白（放松语速念得完），混合有声/静默拍。
- **内容类型**：护肤测评/开箱/晨间routine/好物分享/初体验/真实测评/教程/vlog日常。
- **光源**（自然>人工，指明来源）：自然卧室窗光/浴室镜前灯/黄金时刻阳台光/厨房顶灯/车内仪表光/桌面补光灯(微弱)。
- **机位角度**（描述"怎么拍"）：随意手持自拍角度/手机架在台面/镜子自拍角度/笔记本摄像头角度/单手举着走路拍。

### 第2层 人物（去AI感第一关）
**句式**：`一个 {年龄段} {性别}，{发型}，{皮肤纹理}，穿着 {休闲穿着}，`
- **年龄段**：自然语言，不用精确岁数——年轻女生/30多岁男人/大学生模样的男孩。
- **发型**：随意造型不是沙龙——棕发随意扎起/凌乱丸子头/短卷发/金色挑染夹发夹。
- **⚠️皮肤真实纹理（最易翻车，必带2-3个）**：
  - `自然皮肤纹理可见` / `鼻翼两颊有毛孔` / `肤色略不均` / `轻微黑眼圈` / `额头有自然油光` / `脸颊鼻尖略泛红` / `笑起来有表情纹` / `有淡雀斑(如合适)`
  - ❌ **禁用**：痘痘/粉刺/爆痘/瑕疵/玫瑰痤疮——真实≠皮肤病。
- **穿着**：舒适家居服，不是"今日穿搭"——休闲灰T恤/oversize卫衣/背心短裤/穿旧的格子衫。

### 第3层 场景（背景卖真实）
**句式**：`在 {他/她的空间} —— {杂物1}，{杂物2}，{杂物3}，{氛围词} 且真实。`
| 场景 | 具体杂物细节 | 氛围 |
|---|---|---|
| 卧室 | 书架上有书、窗台绿植、椅子搭衣服、床头彩灯 | 温馨、住过人 |
| 浴室 | 挂毛巾、台面护肤瓶、牙刷杯、雾气镜边 | 蒸汽、清晨 |
| 厨房 | 台面咖啡杯、砧板、果盘、百叶窗晨光 | 温暖、晨间routine |
| 客厅 | 沙发搭毯、坐垫上遥控器、茶几蜡烛、门口鞋 | 放松、随意 |
| 车内 | 杯架咖啡、仪表台墨镜、垂着的AUX线、挡风玻璃外停车场 | 移动中 |
| 书桌 | 半开笔记本、便利贴、水瓶、搭在显示器的耳机 | 居家办公 |
| 阳台 | 背景栏杆、盆栽、可见城市/树、风吹动头发 | 黄金时刻、清新 |

### 第4层 产品引入
**句式**：`{他/她} 把 @(img1)（{产品描述}）{如何拿进画面}。`
- 举给镜头（测评/初体验）/ 已在使用中（教程/routine）/ 开箱掏出(眼睛发亮) / 随手放腿上拿起(vlog) / 举到脸旁转头展示(前后对比)。

### 第5层 脚本节拍（心脏！）
每个节拍 = 一个跳切。结构：**钩子→展示→演示→证据→结论**。
| 拍# | 目的 | 景别 | 动作示例 |
|---|---|---|---|
| 1钩子 | 抓注意 | 看镜头 | 夸张开场，举起产品 |
| 2展示 | 产品细节 | 更近 | 转产品，展示标签/质地 |
| 3演示 | 使用证明 | 大特写 | 涂抹/挤压，展示质地(可静默) |
| 4结果 | 证据 | 镜子/换角度 | 指向效果，前后对比 |
| 5结论 | 最终观点 | 回原角度 | 举起产品，说结论 |
> 10s取2-3拍，15s取3-4拍。任何拍可有声可静默，**每条至少1个静默动作拍**（啜饮/端详/反应/读标签）更真实。

**跳切用语**：`镜头开场——` / `快速跳切——` / `跳切——` / `切到——` / `最后一拍——`
**景别变化(每拍变)**：现在瓶子凑近镜头 / 大特写她挤压滴管 / 手机架着能看到她倒影 / 她凑近镜头 / 她最后再举起瓶子。
**对白铁律**：加引号口语化、用口头禅（"okay所以"/"真的"/"就是那种"/"家人们"/"我真的不是"）、**结尾用半句话或一声笑收尾**，不要精修signoff。每句像不同take拼起来。

### 第6层 语气方向（必带语速提示）
**句式**：`整片语气是 {情绪1}、{情绪2}、{情绪3} —— {行为描述}。`
- **⚠️语速铁律（必带）**：AI默认念太快，必须显式加节奏cue：
  - `每句话之间停顿一下像在想下个词` / `每句说完留一拍静默再继续` / `让画面呼吸——啜一口、低头看一眼、说话前停顿` / `放松不慌的语速，不赶` / `句间自然换气从不赶下一句`
- **语气银行**：
| 人设 | 情绪词 | 行为描述 |
|---|---|---|
| 兴奋粉丝 | 真诚、兴奋、上气不接下气 | 有能量但思考间停顿，自然换气，自嘲笑 |
| 佛系推荐 | 放松、诚实、唠嗑 | 语速慢，句间留白，眼神交流，随意耸肩 |
| 质疑转粉 | 惊讶、佩服、几乎不情愿 | 挑眉，说到一半停顿像在重新考虑，一副难以置信 |
| 闺蜜分享 | 温暖、私密、亲密 | 压低声音，凑近，慢慢说——像分享值得回味的秘密 |
| 晨间随意 | 睡眼惺忪、柔和、不慌 | 打哈欠，动作慢，句间长停顿，喝咖啡间说话 |

### 第7层 剪辑风格
**句式**：`每个跳切 {角度变化}。{剪辑感}。`
- **默认标准**：`每个跳切都稍微更近或换个角度，像她拍了多个take剪了最好的片段拼一起。`
- 变体：紧特写和中景快切、TikTok剪辑节奏 / 一镜到底带1-2个硬切(思考时停顿) / GRWM风格routine每步时间跳跃。

### 第8层 技术瑕疵（去AI感关键·全都要）
**句式**：`光线是 {光型} —— {光瑕疵}。画面略不完美 —— {相机瑕疵1}、{2}、{3}。声音是 {音源} —— {音频细节}。`
- **光瑕疵**：无补光灯无滤镜 / 窗边略过曝 / 半边脸在阴影里。
- **相机瑕疵(选2-3)**：自然手机画质未调色 / 快速移动有轻微运动模糊 / 软焦没有一处纯锐 / 暗部可见噪点 / 跳切间自动白平衡偏移。
- **音源**：手机麦直录(自然人声+房间环境音+无背景音乐) / 前摄麦(略闷+房间回声+背景嗡嗡) / 车内声学(闷+底噪路噪)。

### 第9层 氛围陈述（北极星）
**句式**：`整体感觉是 {形容词1}、{形容词2}、{形容词3} —— {可共情的比喻}。`
- 范例：可信、可共情、真实——像朋友跟你说她真心喜欢的东西 / 混乱、真诚、有趣——像她发给闺蜜群的语音 / 平静、诚实、亲密——像无意听到某人的晨间routine / 兴奋、上气不接下气、有感染力——像她刚发现好物必须马上分享。

## 完整模板（复制填空）

```
{时长} UGC风格 {内容类型} 视频，手机拍摄，{光源}，{机位角度}。一个 {年龄段} {性别}，{发型}，{皮肤纹理}，穿着 {休闲穿着}，在 {空间} —— {杂物1}，{杂物2}，{杂物3}，{氛围} 且真实。{他/她} 把 @(img1)（{产品描述}）{产品引入方式}。

镜头开场——{他/她} {钩子动作}："{钩子台词}"

快速跳切——{第2拍景别}，{第2拍动作}："{第2拍对白}"

跳切——{第3拍景别}，{第3拍动作}。（静默）

跳切——{第4拍景别}，{第4拍动作}："{第4拍对白}" {收尾动作}。

整片语气是 {情绪}——{行为描述}。语速自然不慌——{语速cue}。每个跳切 {角度变化}。{剪辑感}。

光线是 {光型}——{光瑕疵}。画面略不完美——{相机瑕疵}。声音是 {音源}——{音频细节}。

整体感觉是 {氛围形容词}——{可共情比喻}。
```

## 中文范例（护肤精华·卧室·兴奋粉丝）

```
15秒 UGC风格护肤测评视频，手机拍摄，自然卧室窗光，随意手持自拍角度。一个20多岁的年轻女生，棕色头发随意扎起，自然皮肤纹理可见、鼻翼有毛孔、轻微黑眼圈，穿着休闲灰色T恤，在她温馨的卧室里——书架上有书、窗台上有绿植、椅子上搭着衣服，住过人的真实感。她把@(img1)（[品牌]精华，透明滴管瓶）举到镜头前。

镜头开场——她看着镜头，兴奋的表情："家人们，我用了两周，我真的必须来说一下这个。"

快速跳切——现在瓶子凑近镜头，她转动瓶子让光打在质地上："这个质地绝了，像水一样但是很丝滑？"

跳切——大特写她挤压滴管，精华滴到指尖，她在指间揉开展示质地。（静默）

跳切——她凑近镜头，指着脸颊真诚地笑："你们看，我现在真的有光，而且我脸上啥都没涂。"她笑了，画面切断。

整片语气是真诚、不像脚本、温暖——她说得快但用自然停顿，会自嘲笑。语速自然不慌——每句话之间停顿一下像在想下个词。每个跳切都稍微更近或换个角度，像她拍了多个take剪了最好的拼一起。

光线是柔和自然日光，无补光灯无滤镜。画面略不完美——自然手机画质未调色，很真实。声音是手机麦直录——房间环境音、她的自然人声、没有背景音乐。

整体感觉是可信、可共情、真实——像朋友跟你说她真心喜欢的东西。
```

## 自检清单（建prompt前逐条核对）

- [ ] **格式头**：时长(≤15s)/风格/设备/光源/机位全指定
- [ ] **人物**：自然不完美，不是模特试镜
- [ ] **皮肤纹理**：至少2个真实线索(毛孔/不均/油光/黑眼圈)
- [ ] **场景**：3+具体杂物 + 氛围词
- [ ] **产品引入**：产品外观描述清楚 + 如何进画面
- [ ] **脚本节拍**：拍数匹配时长(10s=2-3,15s=3-4) + 含静默拍
- [ ] **对白**：自然语速念得完 + 口头禅 + 自然收尾(笑/半句)
- [ ] **语气方向**：3个情绪词 + 行为描述
- [ ] **语速**：显式语速cue，句间停顿/换气
- [ ] **剪辑风格**：跳切间如何衔接
- [ ] **技术瑕疵**：光瑕疵 + 相机瑕疵 + 音源全指定
- [ ] **氛围陈述**：一句情感比喻锚定全片
- [ ] **字数**：100-260词(Seedance 2.0 甜区)
- [ ] **动作具体**：动作写程度/方向，不只"移动"
- [ ] **一致性锚点**：产品/穿着描述为跨镜头不变
- [ ] **无禁用词**：不用"电影感/专业/惊艳/8k/影棚/完美"

## 中国市场适配要点（板爷补充）
- **平台调性**：小红书偏"真诚种草"用佛系推荐/闺蜜分享语气；抖音偏"强钩子"用兴奋粉丝/质疑转粉。
- **口头禅本土化**：把"you guys"换"家人们/姐妹们"，"literally"换"真的/我真的"，"okay so"换"okay所以/就是说"。
- **场景本土化**：出租屋/合租房/学生宿舍等中国年轻人真实居住场景更有共情。
- **审核**：呼应铁律5，皮肤真实词避开病态描述；正向描述规避。
