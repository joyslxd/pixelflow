# PixelFlow Seedance 分镜提示词规则

本 Skill 只定义如何把已确认的创作合同写成可提交的分镜提示词。它不读取任意文件、
不修改素材、不调用视频生成接口，也不执行安装、更新或网络命令。实际生成必须由受控的
视频 Tool 和 Provider 流程完成。

## 适用范围与模型边界

- 适用于 Seedance 系列的文生视频、图生视频、首尾帧、参考素材和分镜视频生成。
- 只使用 PixelFlow 已提供的剧本、场景包、全局资产和用户材料；不得虚构人物、商品、
  品牌、功效、价格、素材链接或模型能力。
- 画幅、分辨率、总时长、帧率和供应商参数由 Tool 入参控制，不写入 Prompt 正文。
- 用户已明确的角色数量、道具归属、事件因果、空间关系和结局状态是不可改变的创作合同。

## PixelFlow 分镜执行合同

每个分镜都必须是一个可拍摄的连续事件，按下列顺序写清：

1. 地点：场景、时间、环境和必要的空间关系。
2. 主体：出现的角色、商品、道具及其稳定身份。
3. 动作：从开始状态到结束状态的连续动作，不能只写抽象意图。
4. 景别：全景、中景、近景、特写等，并说明关注主体。
5. 运镜：镜头起点、方向、速度和落点；没有必要时保持稳定机位。
6. 光影：可观察的主光、色温、氛围和前后景关系。
7. 声音：环境声、音效、音乐、旁白或对白的来源和时机。
8. 收束：镜头结束时人物、道具、商品和构图必须保持的状态。

分镜正文使用镜内整数秒段，不使用毫秒、小数秒或跨镜头绝对时间码。例如：

```text
0-3秒：地点：晨光厨房。主体：@character-barista 站在木质吧台内侧，@prop-cup 位于右手边。
动作：她拿起杯子完成最后一次搅拌。景别：中近景。运镜：镜头缓慢向杯口推进。
光影：窗边暖光照亮蒸汽。声音：轻微搅拌声与环境咖啡机声。收束：杯子仍在吧台上。
```

多个秒段必须从 0 秒连续覆盖本镜时长；动作、景别、运镜、声音或叙事重点变化时再分段。

## 参考素材与一致性

- `@character-*` 只用于角色外貌、服装和可观察姿态；不得把同一角色拆成多个新人物。
- `@scene-*` 只用于空间布局、建筑、环境和光线；不要继承素材中未被合同确认的人物。
- `@prop-*` 只用于道具或商品的结构、材质、颜色和归属。
- 每个 `@` 实体必须说明在当前镜头中的作用；未声明的素材不得被模型擅自激活。
- 同一角色、商品、道具和场景在连续镜头中保持名称、数量、外观、位置关系和摄影轴线一致。
- 参考视频可继承明确声明的动作、运镜、节奏或声音维度，不自动继承其中的人物身份或品牌。
- 不能读取的素材只保留已确认的引用关系，不假装观察到其内容。

## 声音、对白与字幕

- 对白使用 `说话人：{原文台词}`；只保留用户给出的台词原文，不补写未提供的句子。
- 音效使用 `<音效>`，音乐使用 `(音乐说明)`，画面文字或字幕使用 `【文字】`。
- 多人对话必须逐段注明说话人和其他人物的聆听状态，避免把声音归属交换。
- 无对白时明确人物自然闭口、保留哪些环境声或音效，以及是否不显示字幕。
- 不承诺精确字幕、复杂公式或产品参数的逐字渲染；需要时只描述可观察的画面效果。

## 镜头语言与真实感

- 运镜必须服务当前主体和事件：写清从哪里开始、围绕谁移动、何时结束。
- 情绪使用触发事件加可观察表演表达，例如视线、呼吸、手部动作、姿态、光线或声音变化，
  不能只堆叠“高级感、震撼、治愈”等空泛标签。
- 避免无理由的快速切镜、漂浮镜头、突变造型、突然新增道具或不连续的空间跳转。
- 商品镜头应描述初始状态、单次操作和可观察结果；不得编造价格、功效、认证或绝对承诺。

## 电商与 UGC 场景

- 优先用“人物需求 → 使用动作 → 可观察结果 → 自然收束”的叙事顺序。
- 商品外观、包装文字、数量和关键部件必须与已确认的商品资产一致。
- UGC 场景可使用自然手持感、生活化环境声和真实互动，但不能牺牲主体可见性或品牌安全边界。
- 不自动添加水印、Logo、字幕、负面约束或未确认的卖点。

## 质量检查

输出前逐项核对：

- 每镜有完整的地点、主体、动作、景别、运镜、光影、声音和收束。
- 时间段连续、整数化，并覆盖镜头时长。
- 所有 `@` 引用来自权威场景包或用户明确材料，且作用明确。
- 人物、商品、道具、场景、数量、动作因果和最终状态没有偏离创作合同。
- 没有供应商 URL、Authorization、密钥、内部任务标识、模型思考过程或 Tool 参数。
- 只输出可提交的分镜 Prompt 正文，不输出分析过程、代码围栏、调用命令或生成接口说明。
