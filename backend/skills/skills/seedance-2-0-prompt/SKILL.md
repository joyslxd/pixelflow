# Seedance 2.0 分镜提示词

本 Skill 只把 PixelFlow 已确认的剧本、场景包、素材职责和创作合同整理为可提交的
Seedance 2.0 分镜提示词。它不读取本地文件、不修改 Workspace、不创建 GenerationJob，
也不调用图片、视频或网络接口。

## 使用边界

- 仅用于当前模型档案为 `seedance-2.0`、`seedance-2.0-fast` 或
  `seedance-2.0-mini` 的任务；真实可用时长、画幅、声音、清晰度和参考类型以
  Gateway 的模型档案与 Tool 入参为准。
- 不改写用户已确认的模型、画幅、总时长、商品卖点、角色数量、因果关系、空间关系或
  结局状态。模型能力或 Tool 参数与本 Skill 冲突时，以前者为准并说明不兼容项。
- 只能引用调用方已声明的 `@asset_id`；不得虚构人物、品牌、价格、功效、素材链接、
  模型能力或生成结果。
- 参数属于 Tool 合同：不要在 Prompt 中伪造分辨率、帧率、模型 ID、鉴权或接口参数。

## 输入与产出

输入至少应包含：当前模型、镜头总时长、画幅、视觉风格、故事线或创作合同、可用素材、
对白/旁白意图，以及上一镜的结尾状态（如有）。

输出一个完整 Prompt，不输出分析过程、密钥、Tool 调用指令或局部补丁。每次改写时都
重新给出完整 Prompt，并单列未采用素材；不要要求用户自行拼接片段。

## 分镜合同

1. 单镜按当前模型档案允许的范围组织；标准短镜优先 4--15 个整数秒。只用镜内整数秒
   时间码，例如 `0-4秒`，不用毫秒或小数。
2. 多段必须从 0 秒开始，按顺序连续覆盖整镜，不重叠、不留缺口、不越过总时长。
   动作阶段、景别/运镜、说话者、声音或叙事重点变化时另起段。
3. 每段使用以下字段：`地点`、`主体`、`动作`、`景别`、`运镜`、`光影`、`声音`、
   `收束`。一个短镜只承载一个主要叙事目标和可拍摄的连续事件。
4. 人物、服装、商品、道具、空间朝向和光线必须与创作合同及前后镜保持连续；动作应有
   清楚的开始、过程和结束状态，避免无因果的跳切。

## 素材与声音

- 每镜最多引用 9 张图片，同一素材不重复计数。人物放 `characters`，商品、包装、工具
  与卖点物件放 `props`，环境放 `scenes`。
- 每个引用标明职责，例如“以 `@character-a` 固定人物身份，以 `@prop-bag` 固定商品外观”。
  参考图决定身份和外观，文字决定本镜动作、构图、镜头与声音；冲突时以创作合同和用户
  明确要求为准。
- 有对白或旁白时写明说话者、语气和出现秒段，保证文本能在该时段自然说完；对白留在
  对应时间段，声音块只写声线、配乐和音效，不集中堆放对白。
- 不要求模型渲染可读字幕；价格、Logo、合规文案等由项目既有后期或审核流程处理。

## 画面与电商质量

- 景别和运镜必须服务信息：全景交代空间，中景展示人物与商品关系，近景/特写证明材质
  或卖点。写明镜头起点、方向、速度、落点；不堆砌“电影感”等抽象词。
- 保持手与商品接触、物体比例、重力、空间方向、光源方向和镜面关系可信。只添加少量、
  具体的风险约束，例如额外人物、商品变形、手指异常或无关 Logo。
- 电商镜头按“使用场景或问题 -> 使用动作 -> 可见证据 -> 结果”组织；不得添加未确认的
  价格、折扣、功效承诺或平台话术。
- UGC 可使用轻微手持与生活化构图，但主体、商品和关键动作必须清楚，不能以随机抖动
  冒充真实感。

## 交付前检查

- 时间段、总时长、当前模型与 Tool 合同一致。
- 全部 `@asset_id` 已声明且图片引用不超过 9 张。
- 没有新增商品卖点、价格、Logo、台词或模型能力。
- 每段具备可观察的主体、动作、镜头、光影和声音意图；结尾可承接下一镜或独立收束。
