## 实现边界

- 连接 `/agent/conversations/{conversation_id}/agent-events`，对对话标识和 cursor 编码，并透传 content-app `Authorization`。
- 在 iframe 启动后等待延迟注入的 Authorization；外部 `AbortSignal` 和显式 `close()` 均可中断鉴权、fetch、reader、重连等待和 Snapshot 恢复。
- 按 SSE 空行边界解析 CRLF、心跳、多 frame 分块和多行 `data`，再通过 `parseAgentEventEnvelope` 校验唯一 wire 合同。
- 使用 cursor 断点续传，通过 `event_id + sequence` 幂等，丢弃重复和乱序旧事件；跨对话事件立即 fail-closed。
- 遇到 sequence gap 时不投递越级事件，调用 `reloadSnapshot()` 获取权威 cursor/sequence，清空短期去重集合后重连。
- 瞬时网络错误按配置延迟和次数重连；非 SSE、非成功响应、非法事件、非法恢复点和回调异常均使用固定安全文案，不读取或拼接服务端错误正文。
- SSE 连接在 frame 中途结束时丢弃未由空行终止的残片，从最后成功 cursor 重连，等待服务端补发。
- Snapshot 恢复的普通异常固定映射为 `Supervisor Snapshot 恢复失败` 并立即停止，避免默认无限重连；取消仍保持静默终止语义。
- 单 frame 大小受配置上限保护；致命消费错误会取消底层 reader，避免遗留未消费长连接。
