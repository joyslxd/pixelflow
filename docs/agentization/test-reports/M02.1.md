## 实现合同

- `SupervisorState` 只承载会话身份、当前输入/运行、上下文版本、消息、工作流投影、活动工作流和决策等共享字段；没有提前引入 registry、dispatcher 或图组合。
- `merge_workflow_records()` 按 `workflow_id` 做确定性 upsert，不追加重复条目；输入和输出使用深拷贝，不允许调用方通过嵌套可变对象反向修改 reducer 状态。
- Map 键必须与 `WorkflowRecord.workflow_id` 一致；已有工作流不得变更 `conversation_id` 或 `kind`，错误使用固定中文安全文案 fail-closed。
- Supervisor thread 固定为 `pf:conversation:{conversation_id}:supervisor:v1`；Workflow thread 固定为 `pf:conversation:{conversation_id}:workflow:{workflow_id}:v1`。
- LangGraph 顶层图使用保留的根 `checkpoint_ns=""`；不同会话、Supervisor 与各 Workflow 依靠完整版本化 `thread_id` 隔离。生成的 runnable config 已用真实 checkpointer 验证可恢复。
