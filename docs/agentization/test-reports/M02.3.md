## 实现合同

- 恢复前必须从目标 Workflow namespace 的权威 checkpoint 读取开放中断；请求的 `interrupt_id` 不存在、已关闭或属于其他 thread 时拒绝，不推进 checkpoint。
- 恢复使用 ID 定向 `Command(resume={interrupt_id: response})`，响应先深拷贝，避免调用方后续修改嵌套对象污染图输入。
- Memory checkpointer 证明图对象重建后仍可恢复；文件 SQLite checkpointer 必须关闭第一份资源、重新打开同一数据库后仍从原 interrupt 恢复。
- Workflow 结果只通过 `Command(update=..., goto=...)` 写入 Supervisor reducer，投影在后续节点执行前可见。
- 投影转换必须显式绑定当前 `conversation_id`，不得把其他会话的新 Workflow 插入当前 Supervisor；投影转换不负责选择 active workflow。
- 本片只提供恢复和投影原语，不装配 runtime、graph ID 或 lifespan；这些属于 M02.4。
