## 实现边界

- 新增 `createSupervisorConversationController`，把 Snapshot 恢复、SSE 订阅、四维 reducer 和 Turn/interrupt/status API 组合为单一会话生命周期，作用类似前端工作流编排 Service。
- 新增 `useSupervisorConversation`，通过 `useSyncExternalStore` 暴露状态，通过 effect 建立和清理当前对话 controller；React `StrictMode` effect 重放可在同一 controller 上安全重启。
- 每个 controller 生命周期共享一个 `AbortController` 和递增 generation；切换对话、卸载或 effect 清理后，旧 Snapshot、旧事件、旧错误和忽略 AbortSignal 的迟到 API 结果均不能影响新对话。
- Snapshot 必须属于当前 conversation，恢复后从其 cursor/sequence 订阅；sequence gap 只通过当前会话 Snapshot 恢复，不自动重启 Turn。
- SSE event 只有在 reducer 同步接受并推进相同 cursor/sequence 后才算消费成功；语义非法事件立即固定错误失败关闭，避免 SSE Client 与 reducer 恢复点分叉。
- Turn、interrupt 和 status 请求在 `await` 成功或失败后再次校验 signal 与 generation；失效请求统一返回固定 `AbortError("请求已取消")`，不传播旧会话响应或敏感异常文本。
- 聚合测试脚本只在 Web worktree 内创建临时 hook 编译目录，并在 `finally` 中清理；未新增测试依赖或锁文件变更。
