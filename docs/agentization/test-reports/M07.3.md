## 实现边界

- 以纯 reducer 管理 connection、run、compression 和 input queue 四维状态，并维护 Snapshot/SSE 共用的 cursor 与 sequence 恢复点。
- connection 和 run 使用显式转换表；服务端接管输入后，本地提交失败或重复发送不能把队列状态回退。
- 映射 `run.state_changed`、上下文压缩事件和 `input.state_changed` 的 snake_case wire payload，不在状态中保存原始 payload 或异常正文。
- 重复、乱序和跨对话事件保持幂等隔离；sequence gap 不应用越级事件、不推进恢复点，并进入等待 Snapshot 的可恢复连接状态。
- 语义非法事件使用固定中文安全错误，保持业务投影和恢复点不变，避免跳过坏事件。
- Snapshot 先按对话标识隔离异步旧响应，再验证 run、compression、input queue 和 resume 的结构及交叉约束；旧 Snapshot 不回退 sequence。
- `client_input_id` 与非空 `turn_id` 保持一一绑定；拒绝重绑、服务端状态缺少 Turn ID 和不同输入复用同一 Turn ID。
- 切换对话时原子创建新的空状态，清除上一对话的四维投影、队列和恢复点。
