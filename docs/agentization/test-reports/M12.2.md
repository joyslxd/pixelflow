## 实现合同

- `WorkspaceInteractionPolicy` 是页面交互 ViewModel，相当于把原 Controller 中一个全局 `busy` 拆成三个用途明确的 Filter：输入框 Filter、产物动作 Filter 和运行时状态 Filter。
- `frontend_v2` 保留旧行为：旧业务忙碌、参数弹窗打开或 Plan 修订待选择时，composer 和 artifact 动作同时禁用；尚未创建会话的空白页仍可发送首条输入。
- `supervisor_v1` 运行、压缩或已有排队 Turn 时，composer 仍可提交并由 Supervisor 队列接管；连接 `fatal`、编排归属未决或 Supervisor 会话标识缺失时失败关闭。
- Supervisor 运行态不把 artifact 只读入口统一锁死；会启动旧供应商任务的 handler 继续由 M12.1 `resolveWorkspaceRuntimePolicy` 裁剪，打开、预览和下载保持可用。
- runtime busy 独立综合编排恢复、旧运行时任务、Supervisor run、压缩、连接和本地待提交 Turn，并通过 `aria-busy` 向可访问性和后续 M12.3 UI 投影暴露。
- `Composer` 的属性从含义模糊的 `busy` 改为 `disabled`，发送、选择文件、粘贴和拖拽四类入口共用同一输入策略，上传中的局部禁用保持不变。
