## 实现合同

- `conversation.orchestration_mode` 与 `conversation.orchestration_version` 是唯一编排归属来源；普通 `context` 中同名字段不能伪造 Supervisor。缺失、非法、版本不为 1 或旧 pending 未排空时回退 `frontend_v2`。
- 前端 `ConversationSummaryResponse` 已把两个服务端归属字段声明为可选，兼容当前尚未返回字段的旧网关；后续 Agent Runtime 会话 API 接入前必须返回合法顶层字段，缺失仍保持安全回退。
- 创建新会话后立即解析服务端返回的归属，首次输入不会因为 React state 尚未刷新而误走旧 `/messages/start`；恢复历史会话时在归属确认前暂存输入。
- `frontend_v2` 只挂载旧 runner；`supervisor_v1` 只启用 `useSupervisorConversation`。Supervisor 模式不向 ChatPanel、StoryboardPanel、参数弹窗、Plan 修订和旧画布传入会触发供应商 `/start` 的动作处理器；预览、打开和下载仍可用。
- Supervisor 首个 Turn 必须等待当前对话 Snapshot 连接完成，写请求前刷新 Snapshot 并读取当前 `context_version`，成功接受后再次刷新，避免连续 Turn 使用旧 CAS 版本。
- Hook 在 `enabled=false` 时不请求 Snapshot 或 SSE；切换/卸载通过 M07 的 Abort 和 generation 隔离旧对话结果。
- Supervisor 失败提示使用固定中文安全文案，不展示第三方响应、异常字符串或请求细节。
