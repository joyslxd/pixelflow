## 合同与实现结论

- `AgentRuntimeConfig` 默认值严格为 `mode=off`、`enabled_intents=[]`、`new_conversation_rollout_percent=0`、`context_compaction_enabled=false`。
- `mode`、intent、十进制整数百分比和布尔值采用白名单解析；显式空 intent、未知 profile 键、`null`、空字符串和错误容器类型均在启动时拒绝。
- `backend/tests/fixtures/agent_runtime/contracts-v1.json` 是唯一权威 fixture；Web 测试从该文件生成 TypeScript 常量与类型并使用 `tsc --strict --noEmit` 编译。
- profile YAML 的四个叶子键映射到环境变量，完整中文用途、影响、默认值、范围、重启与回滚说明位于 `backend/pixelflow/agent_runtime/CONFIGURATION.md`。
- M00 只增加配置合同和门禁基础设施，不接管现有图片、视频、PPT 或视频分析业务。
