## 实现合同

### 新对话归属与前端接力

- 创建对话 DTO 增加 `initial_intent` 路由提示。前端只对明确文本做保守推断；“视频分析”先于“视频”匹配，“图生视频”按视频处理，歧义输入返回空提示。
- 服务端只在启动快照为 `primary`、覆盖率为 100 且提示命中 `enabled_intents` 时冻结 `supervisor_v1`。R2 只允许 `video`；图片、PPT、视频分析和歧义输入保持 `frontend_v2`。
- `frontend_v2 + primary` 仍挂载 R1 统一 Turn Runtime，再接力旧 v2；`supervisor_v1` 禁止旧 runner 与旧 Artifact 动作，业务 owner 不双写。

### Replay、Shadow 与 Kill Switch

- `SupervisorReplayRuntime` 在副作用边界前完成模式与 intent 分流。
- `off/assist` 返回 `disabled`，未进入 Graph Handler；未启用业务 intent 返回 `delegated`。
- `shadow` 只保留 `ActionDecision`、`WorkflowCommandPreview` 和共享预算报告，绝不调用 Workflow Handler，因此 Provider start 和 PowerMem record 计数均为 0。
- `primary` 才调用 M02/M05 图；标准视频命令携带 user、Turn、当前输入、materials、reply 和 Artifact 引用，并对嵌套附件做深拷贝。

### 统一上下文合同

- dev 与 prod 均保持 `effective_context_k=896`、`output_reserve_k=32`、`safety_reserve_k=32`，`K=1024 tokens`，可用输入为 832K。
- Replay 通过共享 `ContextBudgetPolicyProvider` 解析 `deepseek-v4-pro`，验证档案为 `max_context_tokens=1000000`；缺失已验证档案时失败关闭。
- 未在视频节点增加窗口常量，未恢复 128K 业务兜底。
- 压缩失败继续使用持久化 30 秒 `retry_not_before`；定向测试验证 30 秒前不领取、边界后恢复同一 Turn 和完整附件。

### Mock E2E 与幂等

- 首轮视频路径串起 M02/M05 Graph、M11 `VideoPlanningWorkflowService` Handler 和标准 `WorkflowCommand`。
- M06 使用 `MemoryCompactionQueueRepository`、`ProviderJobAdapter` 和固定非付费 fake；首次 start 后模拟刷新/进程重建，复用相同 operation 身份、内部 job 与 provider job，重复 start 增量为 0。
- 13 条视频黄金对话覆盖全部 9 类动作，action、target、clarification 均为 100%，计费误执行为 0。

## 审核记录

本周唯一 M13 集成人对最终差异执行只读交叉审核，检查点如下：

- `initial_intent` 只能命中服务端 `enabled_intents`，不替代 Supervisor 权威分类；非视频和歧义输入保留旧 owner。
- Shadow 在 Handler、Operation、PowerMem record 之前返回，标准预览不包含 Authorization、供应商请求或真实凭据。
- 视频附件、reply 和 Artifact 引用进入同一命令快照，Handler 修改副本不会污染原 Turn。
- 重复 start 只回读稳定 Operation/provider job；测试使用固定假凭据且报告、状态和日志均未记录该值。
- dev 只开放 `video`；prod 无差异。所有配置叶子项有紧邻中文用途、影响、重启与回滚说明。
- 新增/修改注释、docstring、JSDoc、状态、测试结论和交接说明均使用中文语义；机器字段、类名和协议值保留英文。
- 统一预算只来自共享 Provider；严格模型档案和 30 秒退避未被绕过。

审核结论：R2 变更未发现 Critical、Important 或 Minor 遗留问题，可以形成阶段候选。此结论只授权写 `ready_for_phase_integration:R2`，不授权生产发布、真实付费验证或 M13.3。
