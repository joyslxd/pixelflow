## 实现合同

- 新增 `VideoScenePackageWorkflowService`，只接受处于 `PLAN_APPROVED/RUNNING` 的 M11.1 权威状态；`PLAN_REVIEW/AWAITING_USER` 不得被当成已同意，用户必须先经过显式 `approve_plan()` 转换。
- `VideoScenePackageAuthoritySnapshot` 以规范 JSON 和 SHA-256 冻结来源 Plan 校验和、Plan 版本、创作合同、输入素材 URL、目标时长、场景包、全局资产及资产图生成状态；调用方只能取得隔离副本。
- 每次准备、恢复和 Runtime DTO 投影都会重建 Plan 当前值、完整历史、合同、分镜蓝图与资产清单校验链，隐藏历史篡改、Plan 后缀注入和伪造审核态均失败关闭。
- 场景包必须逐镜精确继承权威 `scene_id`、顺序、整数秒时长、故事线、镜头描述、旁白、转场和引用资产；Prompt 只机械组合权威字段并显式携带合同 `video_model`，禁止二次 LLM 改写和额外供应商字段。
- 输入素材只接受规范 HTTPS 图片 URL，并冻结去重后的精确集合；每镜不得替换、删除或增加素材 URL。
- 全局资产四类 ID 全局唯一，每镜最多引用 9 个资产；生成阶段要求每个角色、场景和道具恰好绑定一张规范 HTTPS 图片，再机械回填镜头 mention，缺失、重复、额外或非规范 URL 均失败关闭。
- 共享旧 v2 helper 新增默认关闭的 `authority_mode`。旧 Router 和 LLM wrapper 不启用时继续使用原 Prompt 与顺序场景 ID；仅 M11.2 Service 显式启用权威模式，避免 Feature Flag 关闭时改变现有 v2 行为。
