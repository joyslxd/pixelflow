## 结构与边界结论

- `ContextSummary` 保持 M00 冻结字段不变，新增单条 DTO 内可判定的前驱、证据引用和消息前缀覆盖约束。
- `StructuredSummaryRepository` 相当于领域 Service/Repository：先复制调用方摘要，再校验已有链和下一版，读取同用户同会话权威证据快照，校验消息顺序与 Artifact 存在性，最后调用 M01 Repository 持久化。
- 首版必须是 v1；后续版本必须连续并指向当前最新摘要；覆盖范围只能累计扩展，既有消息 ID 前缀不得改写。
- 证据校验和版本校验均在底层写入前 fail-closed；成功或失败路径都不修改来源摘要、原始消息或 Artifact 证据快照。
- 未实现 M04.2 SummaryBuilder、M04.3 四阈值 Coordinator、M04.4 压缩锁/输入队列或 M04.5 压缩事件/SummaryVerifier。
- 未修改配置、数据库表、migration、长期 feature 分支或 `status/BOARD.md`；未调用真实 LLM、PowerMem、图片、视频、PPT、剪映或其他付费 API。
