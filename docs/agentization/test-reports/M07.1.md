## 实现边界

- 提供 snapshot、Turn 启动、Interrupt 响应和运行状态四类请求。
- 统一使用 `/agent` 前缀，对 conversation、interrupt 和 run 标识执行 URL 编码。
- 透传 content-app `Authorization`，并等待 iframe 启动后的延迟鉴权注入。
- 同一个 `AbortSignal` 覆盖请求前、异步鉴权等待和 fetch 阶段。
- 响应泛型约束为 `JsonValue`；204 和非法 JSON 均作为稳定的 502 协议错误处理。
- 非 2xx 响应不读取、不信任服务端正文，只保留 HTTP 状态和固定中文公开文案，避免泄露 token、异常堆栈或部署目录。
