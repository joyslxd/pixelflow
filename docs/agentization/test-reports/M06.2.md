## 租约合同结论

- operation 领取同时匹配 `user_id + conversation_id + job_id`；不匹配时统一返回 `None`，不泄露其他用户或其他对话的任务。
- 只有 `status=polling`、`provider_job_id` 已落库且 `next_poll_at <= now` 的 operation 可领取；`created`、全部终态、缺少 Provider 引用、未排期或尚未到期任务均不可领取。
- Memory 使用 operation 专用锁；SQL 在同一写事务内读写锁定行，SQLite 用 `BEGIN IMMEDIATE` 让指向同一文件的两个独立 Engine 也只能产生一个胜出 worker。
- 有效租约内同 worker 重领只回读原租约，不隐式续期；其他 worker 无法领取。heartbeat 只允许当前未过期持有者把截止时间严格延长。
- 一次轮询结束后，当前持有者在同一原子写入中保存未来 `next_poll_at` 并清空租约；到期前无法重新领取。
- `lease_expires_at == now` 视为过期，新 worker 可以接管；旧 worker 随即不能 heartbeat 或排期，失败调用不改变数据库。
- 时间输入必须包含时区；租约截止时间和下一轮轮询时间必须严格晚于本次操作时间。
