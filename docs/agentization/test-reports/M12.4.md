## 实现合同

- `buildSupervisorSubmission()` 相当于前端 Application Service：输入是 Composer DTO 与当前 CAS 版本，输出只能是冻结 `TurnStartRequest` 或 interrupt response，不让页面直接拼接两套传输合同。
- reply 先读取显式 `reply_to_message_id`，并兼容场景素材已有的 `reply_to_message_id/storyboard_message_id`；出现不同目标时失败关闭，不按“最近消息”猜测。
- Artifact 引用从显式 `artifact_refs` 及素材已有的 `artifact_ref/artifact_refs/mention_ref/mention_refs` 提取，只转发合法 `artifact:` 引用并保持首次出现顺序；不凭空生成 M11 hash 引用。
- 场景素材原样保留 `asset_id`、`storyboard_message_id` 和已有 Artifact/mention 证据，同时附加当前 `conversation_id`；提交前拒绝跨会话归属。
- 合法 `interrupt_id` 使用 `interrupt_id + client_response_id` 幂等合同，只调用 `respondToInterrupt()`；response 的 `value` 携带与 Turn 等价的 content、materials、reply 和 Artifact 指向。
- `frontend_v2` 继续进入原可恢复 intake/旧 runner；Supervisor 仅开放建立 Composer 引用所需的场景素材入口，旧供应商生成、替换和重试动作仍关闭。
