## 发布入口门禁失败

仓库仅提供生产打包脚本，没有远端 CI、生产部署脚本、服务器地址、服务重启命令、日志/指标查询入口或原子回滚命令。R1 发布记录也明确由发布负责人人工上传发布包并重启，未沉淀可委托的自动化入口。

当前机器进一步复核到：

- 没有 SSH 目标配置；
- 没有已登录的生产发布平台页面；
- 没有其他可验证的生产部署连接；
- 自动化状态仍为 `automation_local_ready`，不得提升为 `automation_active`。

因此无法保证“改配置后立即部署、执行非付费 smoke、观察指标、异常时原子恢复 R1”。继续修改仓库生产配置会产生无法安全完成的半发布状态，故必须在变更前停止。
