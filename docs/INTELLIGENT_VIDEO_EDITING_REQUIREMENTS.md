# PixelFlow 智能剪辑需求说明

> 状态：需求基线，未开始实现
>
> 目标：让用户上传视频或选用 PixelFlow 已生成视频后，用自然语言得到可预览、可修改、可追溯的剪辑方案，并在确认后渲染成片。

## 1. 产品定位

智能剪辑不是“自动把若干视频拼起来”，而是把用户的剪辑意图转换成一个可编辑的成片方案。用户说出目标，例如“做成一支 30 秒、有故事感的品牌片”，系统应理解素材、筛选镜头、规划叙事、给出时间线和版本选择，再执行渲染。

产品承诺是“智能编排 + 用户可控 + 成片可追溯”，不是“任意素材一键生成专业大片”，也不是“输入任意第三方链接一键复刻原视频”。

## 2. 目标用户与输入

适用用户：电商商家、品牌运营、内容创作者和非专业剪辑人员。

可用输入：

- 用户上传并声明拥有使用权的视频、图片、音频和 Logo。
- PixelFlow 当前会话中已生成、且归当前用户所有的视频和图片。
- 用户提供的品牌资料、目标平台、时长、画幅、受众和文案。
- 授权状态明确的音乐、音效、字体和贴纸素材。

不可直接使用：来源或授权不明的第三方音乐、素材、字体、人物肖像、品牌标识和完整文案。

## 3. 核心用户旅程

```text
上传/选择素材
  → 描述剪辑意图
  → 素材分析与镜头建议
  → 可编辑 Timeline 草案
  → 用户确认渲染范围与成本
  → 成片渲染、质量检查
  → 多版本交付与授权清单
```

## 4. 功能需求

### 4.1 素材分析

- 读取时长、分辨率、帧率、编码、音轨和响度等媒体元数据。
- 提取关键帧，识别场景切换、黑屏、模糊、过曝、重复镜头和明显异常。
- 识别人物、主要动作、对白、环境声、字幕和节奏点；所有模型结论应携带时间范围和置信度。
- 输出“建议保留/建议排除/需要人工确认”的镜头清单；不得自动删除原始素材。

### 4.2 智能筛选与故事规划

- 依据清晰度、稳定性、曝光、构图、动作完整度、内容重复度和叙事价值生成候选镜头。
- 根据用户目标输出可选择的故事结构，如抒情叙事、快节奏短视频、宣传片和纪录片。
- 用户可以修改时长、顺序、保留镜头、节奏、文案和版本目标。
- 叙事价值、情绪贡献等属于建议，不得成为不可解释的硬删除规则。

### 4.3 Timeline 编辑

- 支持裁剪、排序、拼接、删除、静音、速度调整和画幅适配。
- 支持 `cut`、淡入淡出、叠化等基础转场；复杂扫描、遮罩和动态转场后续提供。
- 支持原声保留、替换、混音、淡入淡出、背景音乐闪避和响度控制。
- 支持标题、字幕、花字、贴纸、图片、Logo 和片尾署名。
- 所有改动可预览、可撤销，且保留版本记录。

### 4.4 音乐、音效和授权

- 支持用户上传音乐、授权音乐库、开源音乐/音效库和后续可选的音乐生成 Provider。
- 每一条外部音乐/音效必须保存来源、许可证、作者、署名要求、商业使用状态和适用平台。
- 优先选择 CC0、CC BY 或明确允许商用的素材；对非商用、限制二次分发或授权不明的素材拦截或提示。
- 音效仅从登记且授权明确的 Catalog 选取，不从网络任意抓取。

### 4.5 字幕、包装与质量检查

- 通过 ASR 生成可编辑字幕，自动断句和对齐时间轴；错误文本必须允许用户修改。
- 按目标平台检查字幕安全区、字体大小、可读性和对比度。
- 导出前检查黑帧、花帧、卡顿、音画不同步、爆音、音量过低、转场突兀、字幕越界、色彩不一致和授权缺失。
- 不通过质量检查时，给出可理解的修复建议，不能伪造成片成功。

### 4.6 输出与版本

- 支持高质量母版、16:9 横屏、9:16 竖屏、1:1 方形、无音乐版和带字幕版。
- 每个输出版本保存来源 Timeline revision、输入 Artifact、渲染配置、质量结果和授权快照。
- 可选导出剪映草稿；剪映工程仅为交付物，不是系统权威编辑状态。

## 5. 分期范围

| 阶段 | 范围 |
| --- | --- |
| P0 | 素材元数据、Timeline 草案、裁剪/拼接、基础转场、原声/背景音、基础字幕、质量检查、16:9/9:16 输出 |
| P1 | 节拍分析、自动字幕增强、镜头语义建议、音乐/音效授权 Catalog、ducking、HyperFrames 动态包装 |
| P2 | 目标跟踪贴纸、关键帧、复杂动效、剪映草稿导出、更多渲染 Provider |

## 6. 明确非目标

- 不实现专业非线性剪辑软件的全量能力，如复杂调色节点、三维合成、任意插件和高级遮罩。
- 不以用户自然语言直接执行 Shell、FFmpeg 参数、HTML 或 JavaScript。
- 不自动采集、下载或复刻未授权的第三方作品。
- 不让模型在未预览、未确认时启动可能计费或长时间渲染的操作。

## 7. 验收标准

- 用户可以从三个或以上授权视频获得一份可修改的故事化 Timeline 草案。
- 用户可以修改草案并看到版本变化；并发修改不会丢失内容。
- 渲染前必须明确素材范围、输出版本、授权状态和用户确认。
- 成片只在质量检查通过后交付；失败时能返回安全、可行动的错误摘要。
- 用户可查看每个交付版本使用了哪些素材、音乐及其授权信息。
